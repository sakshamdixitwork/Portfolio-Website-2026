# Saksham Dixit — Portfolio Website

A dark & techy personal portfolio built with pure HTML, CSS, and vanilla JavaScript.

## 📁 Project Structure

```
saksham-portfolio/
├── index.html          ← Main HTML file
├── css/
│   └── style.css       ← All styles (dark theme, responsive)
├── js/
│   └── main.js         ← Interactions & animations
├── resume-pm.pdf       ← ⚠️ Add your PM resume here
├── resume-gamedev.pdf  ← ⚠️ Add your Game Dev resume here
└── README.md
```

## 🚀 How to Use

1. Open `index.html` in any browser — no build tools needed.
2. Add your resume PDFs to the root folder named:
   - `resume-pm.pdf`
   - `resume-gamedev.pdf`
3. Update your LinkedIn, GitHub, Upwork links in `index.html`.

## ✏️ What to Customize

### In `index.html`:
- Replace placeholder LinkedIn/GitHub/Upwork URLs
- Update contact information (email, phone, location)
- Add events/conferences you've personally attended (Section 04)
- Add blog post links when you publish articles (Section 05)
- Add project screenshots or Figma embed links inside `.proj-card` divs

## 🌐 Hosting (Free Options)

### GitHub Pages
1. Push this folder to a GitHub repository
2. Go to Settings → Pages → Deploy from main branch
3. Your site goes live at `https://yourusername.github.io/repo-name`

### Netlify
1. Go to netlify.com → "Add new site" → "Deploy manually"
2. Drag and drop this entire folder
3. Live in 30 seconds

### Vercel
1. Push to GitHub
2. Import repo at vercel.com
3. Done — auto-deploys on every push
